--------------------------------------------------------------------------
1. PROJECT OVERVIEW
--------------------------------------------------------------------------
PhishGuard is an intelligent cybersecurity application designed to analyze,
classify, and block phishing URLs in real time. Rather than relying solely 
on static blacklists (which fail against new, zero-day links), PhishGuard 
uses a trained Random Forest Classifier to extract semantic and structural 
features from a URL and compute a mathematical probability of it being a 
phishing threat.

--------------------------------------------------------------------------
2. HOW IT WORKS (SYSTEM PIPELINE)
--------------------------------------------------------------------------
The entire process from scanning a URL to visualizing it on the dashboard 
follows a strict sequential pipeline:

Step 1: Input & Sanitization
  - The user enters a URL in the UI (e.g. single scan or batch file upload).
  - The URL is sanitized (stripping whitespaces and control characters) and 
    validated. The validation supports standard domains, raw IP domains 
    (e.g., http://192.168.1.1), and localhosts.

Step 2: Feature Extraction (backend/feature_extractor.py)
  - The URL string is parsed into 15 distinct numerical and binary features:
    1. url_length: Total character count.
    2. domain_length: Length of the domain portion.
    3. dots_count: Number of dots (.) in the string.
    4. hyphens_count: Number of hyphens (-) in the string.
    5. digits_count: Count of numeric digits.
    6. subdomains_count: Count of subdomain partitions.
    7. https_present: Binary indicator (1 if HTTPS protocol is used, 0 if HTTP).
    8. ip_present: Binary indicator (1 if domain is a raw IP address, 0 otherwise).
    9. keywords_count: Count of sensitive keywords (e.g. "login", "bank", "secure").
    10. special_chars_count: Number of special characters (?, =, &, _, %).
    11. redirect_count: Number of redirect parameters or double slashes in path.
    12. at_present: Binary indicator of the presence of the '@' symbol.
    13. double_slash_present: Binary indicator of extra '//' in URL path/queries.
    14. entropy_score: Shannon entropy score measuring string randomness.
    15. tld_risk_score: Numerical risk weight based on top-level domain extensions (.xyz, .top, etc.).

Step 3: Machine Learning Inference (backend/app.py)
  - The extracted features are fed into a trained Scikit-Learn Random Forest 
    Classifier model.
  - The model outputs a continuous probability score (0.0 to 1.0) indicating 
    the likelihood of phishing.
  - Continuous probability is mapped into 3 risk levels:
    * Probability < 0.35: SAFE (Low Risk)
    * 0.35 <= Probability < 0.65: SUSPICIOUS (Medium Risk)
    * Probability >= 0.65: PHISHING (High Risk)
  - If the pickle model file is ever missing or corrupt, app.py falls back 
    to a defensive heuristic rules classifier to prevent server crashes.

Step 4: Database Storage (backend/database.py)
  - The scan result is stored in the scans table of the SQLite database.
  - Fields saved: URL, prediction (Safe/Suspicious/Phishing), confidence 
    score, risk level, timestamp, and actual_label (if evaluated via CSV).
  - Bulk scans are saved in a single, optimized transaction using SQLite 
    executemany to prevent database file locks on Windows.

Step 5: Frontend State Update (frontend/src/app/page.tsx)
  - The frontend uses SWR (Stale-While-Revalidate) for data fetching.
  - On scan completion, a global SWR mutation is called. This invalidates 
    the cache and triggers instant, seamless refreshes of dashboard statistics 
    and model metrics without requiring a full page reload.

--------------------------------------------------------------------------
3. CORE FEATURES
--------------------------------------------------------------------------
1. Real-Time Single URL Scanner:
   - Includes real-time character and dot counters that update as you type.
   - Displays prediction, confidence bar, risk level badge, extracted features, 
     and specific security recommendations.
2. Bulk Threat Scanner:
   - Supports plain text (.txt) and comma-separated (.csv) file uploads.
   - Evaluates up to 500 URLs.
   - Checks if the CSV contains a ground-truth label column. If present, 
     actual labels are saved to SQLite to update the confusion matrix.
   - Invalid URLs are returned as "Invalid" instead of crashing the batch.
   - Downloads results as a CSV.
3. Interactive Security Dashboard:
   - Dynamic cards showing Total Scans, Safe count, Suspicious count, 
     Phishing count, Detection Rate, and Average Confidence.
   - Displays latest scan timestamp (e.g. "Latest: 12:45 PM") under Total Scans.
   - Recharts-based interactive Area Chart (trends over time), Pie Chart 
     (threat distribution), and Bar Chart (threat breakdowns).
4. Model Architecture & Evaluation Page:
   - Accuracy, Precision, Recall, F1, and Cross Validation scores.
   - Dynamic Confusion Matrix calculated from prediction records containing 
     an actual label. Displays a fallback warning if labeled records < 5.
   - Feature Importance ranking showing relative weights of URL features.

--------------------------------------------------------------------------
4. LANGUAGES, TECHNOLOGIES, AND LIBRARIES USED
--------------------------------------------------------------------------
A. Programming Languages:
   - Python: Used for the backend API, machine learning pipeline, dataset 
     generation, and model training.
   - TypeScript / JavaScript: Used for frontend logic, React components, 
     and client state management.
   - HTML5 & CSS3: Structure and styled theme (glassmorphism/cyberpunk).

B. Backend & Database Stack:
   - Flask: Micro-framework serving backend endpoints.
   - Flask-CORS: Manages Cross-Origin Resource Sharing.
   - Flask-Limiter: Applies rate-limiting (e.g., max 60 requests/min).
   - SQLite3: Light, local relational database.

C. Machine Learning Stack:
   - Scikit-Learn: Trains the Random Forest Classifier, runs GridSearchCV 
     hyperparameter tuning, and evaluates confusion matrices.
   - Pandas: Data manipulation and parsing (CSVs).
   - NumPy: Mathematical operations.

D. Frontend Stack:
   - Next.js (16.2.9 - App Router): React framework.
   - React (19.2.4): UI component rendering.
   - SWR (2.4.1): Frontend cache management, mutation, and data-fetching.
   - Recharts (3.8.1): Dynamic SVG charting libraries.
   - TailwindCSS: Clean CSS layout styling.
   - Framer Motion: Fluid animations and page transitions.
   - Lucide React: Cyber-themed vector icons.

--------------------------------------------------------------------------

   in your default web browser.
