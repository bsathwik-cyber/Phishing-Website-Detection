# Frontend

The PhishGuard user interface is a Next.js App Router application.

For the complete project overview, prerequisites, backend setup, frontend setup, API endpoints, data handling notes, and limitations, see the [root README](../README.md).

## Local development

From this directory:

```bash
npm install
npm run dev
```

The frontend expects the Flask API at `http://127.0.0.1:5001` during local development.
